## Feature Flag → Plan Mapping (Database Reference)

These are the `crm_feature_flags` columns mapped to plans. Use this when enforcing plan limits in code:

```sql
-- Example feature flag check
SELECT crm_enabled, max_customers, max_brands, ai_credits_monthly,
       max_team_members, inbox_enabled, analytics_level, custom_roles_enabled,
       audit_logs_enabled, api_access_enabled, export_enabled, white_label_enabled
FROM workspace_plan_features
WHERE workspace_id = $1;
```
